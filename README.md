# Digital SAT Bluebook Simulator 📘

College Board rasmiy Question Bank bazasi asosida yaratilgan **Digital SAT Bluebook Simulator** platformasi.

**Muallif:** `Otabek_N`

---

## 🚀 Asosiy imkoniyatlar:
- **1,153 ta rasmiy savol:** College Board test bazasidan olingan yuqori aniqlikdagi grafik va jadvalli savollar.
- **Rasmiy interfeys:** College Board Bluebook dizayni, vaqt hisoblagichi, savollarni belgilash (Mark for Review), formulalar varaqasi.
- **O'rnatilgan Desmos kalkulyatori:** Rasmiy SAT Desmos Graphing Calculator integratsiyasi.
- **Ikki tomonlama tushuntirishlar:**
  1. Rasmiy College Board yechimi (original).
  2. Har bir savol uchun o'zbek tilidagi batafsil bosqichma-bosqich izohlar.
- **Adaptiv algoritm:** 1-modul natijasiga ko'ra 2-modul qiyinlik darajasining moslashishi.
- **Natijalar tarixi:** Barcha topshirilgan testlar natijalari brauzer xotirasida avtomatik saqlanib boradi.
- **To'liq moslashuvchanlik:** Kompyuter, noutbuk, planshet va smartfonlarda to'liq ishlaydi.
